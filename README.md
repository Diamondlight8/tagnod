# TagNod

NFC-powered macro automation for Android.  
Tap a tag, execute any action. Free alternative to MacroDroid.

## How it works
1. Add your NFC tags & Apps as Triggers
2. Build a macro — chain any actions together
3. Assign a tag or app launch trigger to the macro
4. Tap from anywhere — no need to open the app

## Features
- NFC and App Launch triggers
- Grayscale toggle via Daltonizer
- Full import/export configuration
- AMOLED dark mode with accent colour options
- No account, no cloud, no subscription

## Install
Download the APK from [Releases](https://github.com/Diamondlight8/tagnod/releases)  
Enable "Install from unknown sources" and install.
